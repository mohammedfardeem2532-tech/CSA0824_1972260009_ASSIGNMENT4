## Assignment Overview

**Topic:** Robust Data Processing with Files, Exceptions, Modules and Packages.

This assignment contains six tasks that demonstrate how Python can be used to process files, handle invalid records, manage errors, organize code into modules and packages, and generate useful reports.

## Tasks Included

### Task 1 – File-Processing Design Review
**Hostel Mess Bills**

- Process hostel mess bill records from a text file.
- Validate the input fields and bill amounts.
- Handle invalid amounts and missing fields.
- Calculate the grand total using Python's `Decimal` module.
- Display valid records and rejected lines.

### Task 2 – File-Processing Design
**Biometric Attendance Files**

- Read multiple attendance files.
- Process Present (P) and Absent (A) records.
- Calculate attendance percentages.
- Generate a summary report.
- Identify students with attendance below 75%.
- Record damaged records in an error log.

### Task 3 – Error Handling and Exceptions
**Attendance Processor**

- Create a custom exception named `InvalidRecord`.
- Validate attendance records.
- Handle missing files and invalid records.
- Use `try`, `except`, `else`, and `finally`.
- Display valid attendance counts and error details.

### Task 4 – File and Exception Forensics
**Library Book Returns Log**

- Process daily library book return files.
- Store book return records using append mode.
- Use context managers for file handling.
- Handle missing files and file-related errors.
- Maintain a separate error log.

### Task 5 – Scripts, Modules and Packages
**Attendance Utility**

- Organize the attendance utility into separate modules.
- Use `reader.py`, `stats.py`, and `report.py`.
- Calculate attendance percentages.
- Identify three or more consecutive absences.
- Generate an attendance summary report.

### Task 6 – Design Challenge
**College Fest Registration Desk Package**

- Process student registration files from different departments.
- Validate email addresses.
- Detect duplicate registration numbers.
- Generate a master registration list.
- Create separate event-wise CSV files.
- Record invalid and missing records in an error log.
